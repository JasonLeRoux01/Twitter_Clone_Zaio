# Twitter/X Clone - South Africa Solo Project

## 🐦 Project Overview
A pixel-perfect clone of X.com (formerly Twitter) home feed with South African focus. Built with HTML5, CSS3, and vanilla JavaScript.

## 🎯 Features
- **Left Sidebar** - Complete navigation with 12+ authentic X.com icons (Home, Explore, Notifications, Follow, Chat, Grok, Bookmarks, Creator Studio, Premium, Profile, More)
- **Main Feed** - "For you" / "Following" tabs with sticky header
- **Right Sidebar** - Search bar ready for trends & recommendations
- **Dark theme** - Perfect X.com styling (#0f1419 bg, #1d9bf0 blue)
- **Responsive** - Mobile-first three-column layout
- **Hover effects** - Authentic X.com interactions
